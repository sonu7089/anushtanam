# Anushtanam 2.0

Release name: **2.0 - A Deeper Daily Practice**

Android version: `2.0` (version code `12`).
Application ID: `shastralife.anushtanam`.

## Google Play release notes

```text
Deepen your daily practice with Anushtanam 2.0:
- Refined Sandhya and japa tracking with clearer goals and progress.
- A Gayatri practice guide and improved reminder controls.
- Google sign-in and easier family linking with QR codes or ID and PIN.
- Automatic practice backup, recovery, and sync status.
- Teachings, messages, mentor reflections, and optional notifications.
- Refined layouts, dark mode, and support for larger text.
```

## Release build

Build the signed, optimized Android App Bundle using the existing local upload key:

```powershell
.\gradlew.bat :app:bundleRelease
```

Bundle: `frontend/android/build/outputs/bundle/release/app-release.aab`.

The upload keystore and its properties remain local and excluded from Git.
Build logs are stored under the ignored `build/release-2.0/` directory.
